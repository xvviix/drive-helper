# Drive Helper Pro 🧰

**فارسی** | [English below](#english)

جعبه‌ابزار قابل‌حمل عیب‌یابی، تعمیر، بکاپ و نجات ویندوز — همه‌چیز در **یک فایل Batch**، بدون نصب و بدون اینترنت.

- 📦 تک‌فایل: فقط `DriveHelper.bat` را روی فلش بریزید و اجرا کنید
- 🪟 ویندوز 8.1 / 10 / 11 — ۳۲ و ۶۴ بیتی
- 🚑 **حالت نجات**: در محیط Windows Recovery (وقتی ویندوز بالا نمی‌آید) خودکار فعال می‌شود
- 🔍 بیش از ۴۰ ابزار در ۶ دسته: سلامت هارد، SFC/DISM، تعمیر بوت، chkdsk، فرمت با تایید چندمرحله‌ای، کپی/زیپ، بکاپ کاربر و تصویر سیستم، رمز وای‌فای، بکاپ درایور، فلش Rescue بوت‌able و...

# English

A portable Windows troubleshooting, repair, backup and rescue toolkit — everything in a **single batch file**, no install, no internet required.

- 📦 Single file: just put `DriveHelper.bat` on a USB stick and run it
- 🪟 Windows 8.1 / 10 / 11 — 32 & 64 bit
- 🚑 **Recovery Mode**: activates automatically inside Windows Recovery (WinRE) when Windows will not boot
- 🔍 40+ tools in 6 categories: disk health, SFC/DISM, boot repair, chkdsk, guarded format, copy/zip, user & image backup, WiFi passwords, driver backup, bootable rescue USB and more
