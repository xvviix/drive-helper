راهنمای نجات — وقتی ویندوز بالا نمی‌آید (Recovery)
=====================================================

وقتی ویندوز بوت نمی‌شود، DriveHelper.bat خودش را به «حالت بازیابی»
(RECOVERY MODE) می‌برد — فقط باید بتوانی آن را از داخل محیط
Windows RE اجرا کنی:

ورود به Windows RE (یکی از این راه‌ها):
-----------------------------------------------------
راه ۱ — از روی خود سیستم:
  ویندوز را ۳ بار پشت‌سرهم هنگام بوت قطع کن (روشن کن، وقتی لوگوی
  ویندوز آمد دکمه_power را بگیر خاموش کن) — بار سوم ویندوز خودش
  وارد محیط Recovery می‌شود.

راه ۲ — از بوت منو:
  سیستم را ری‌استارت کن و مدام F11 یا Esc یا F12 را بزن (بسته به
  برند لپ‌تاپ فرق دارد) → Boot Menu یا Windows Recovery.

راه ۳ — با فلش نصب ویندوز:
  فلش Bootable ویندوز بساز (با Media Creation Tool از یک سیستم
  سالم) → از آن بوت کن → صفحه‌ی اول → Next → Repair your computer.

مراحل بعد از ورود:
-----------------------------------------------------
1) Troubleshoot → Advanced options → Command Prompt
2) حرف درایو یو‌اس‌بی را پیدا کن (در این محیط حرف‌ها فرق دارند!):
       dir c:\   dir d:\   dir e:\   dir f:\
   وقتی فایل DriveHelper.bat را دیدی، همان حرف است.
3) اجرا:
       e:\DriveHelper.bat
   (به‌جای e حرف درایو خودت را بزن)

برنامه خودش بالای صفحه لیست درایوها را نشان می‌دهد و کنار درایوی که
ویندوز رویش نصب است می‌نویسد [WINDOWS INSTALLATION FOUND].

پیشنهاد ترتیب کار برای «ویندوز بوت نمی‌شود»:
-----------------------------------------------------
گزینه ۵ (Boot repair)  ← اولین کاری که باید بکنی؛ اکثر مشکل‌های
                          بوت با fixboot + rebuildbcd حل می‌شود
گزینه ۳ (chkdsk)       ← اگر خطای دیسک می‌دهد
گزینه ۴ (SFC آفلاین)   ← اگر فایل‌های ویندوز خراب شده‌اند
گزینه ۲ (Rescue copy)  ← اول فایل‌های مهمت را دربیار، بعد هر کاری
                          خواستی بکن!
گزینه ۱ (لیست درایوها) ← همیشه اول این را ببین

نکته‌های مهم:
-----------------------------------------------------
- در محیط بازیابی، دسترسی کامل SYSTEM داری؛ مراقب با گزینه‌های
  حذف و فرمت باش.
- گزینه ۹ برای ری‌استارت بعد از تعمیر است.
- اگر هیچ درایوی «ویندوز نصب‌شده» نداشت، احتمالاً پارتیشن خراب
  است → گزینه ۷ (DISKPART) → list volume → وضعیت پارتیشن را ببین.
