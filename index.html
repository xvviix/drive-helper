این چیست؟

Drive Helper Pro یک فایل Batch ویندوز است که مثل یک جعبه‌ابزار همراه عمل می‌کند: روی فلش USB بریزیدش و هر جا سیستمی به مشکل خورد، اجرایش کنید. منوی فارسی‌پسند (متن انگلیسی)، لیست زنده‌ی درایوها با حجم، و بیش از ۴۰ ابزار در ۶ دسته.

چرا تک‌فایل؟ نه نصب می‌خواهد، نه اینترنت، نه برنامه‌ی اضافه. فقط cmd و PowerShell خود ویندوز — روی هر سیستمی حتی بدون دسترسی ادمین (برای ابزارهای ادمین، خودش پنجره‌ی UAC باز می‌کند).

What is this?

Drive Helper Pro is a Windows batch file that works like a pocket toolbox: put it on a USB stick and run it wherever a PC is in trouble. Clean English menus, a live drive list with sizes, and 40+ tools in 6 categories.

Why a single file? No install, no internet, no extra software — only the cmd and PowerShell already inside Windows. It even relaunches itself elevated via UAC when an admin tool needs it.

وقتی ویندوز بالا نمی‌آید

برنامه در محیط Windows Recovery (WinRE) خودکار وارد حالت نجات می‌شود و فقط از ابزارهایی استفاده می‌کند که در آن محیط واقعاً موجودند.

مهم در WinRE اینترنت معمولاً وجود ندارد؛ وای‌فای تقریباً هرگز کار نمی‌کند و کابل شبکه فقط گاهی با wpeutil InitializeNetwork. به همین دلیل ابزارهای آنلاین عمداً در این حالت حذف شده‌اند.
  1. ورود به WinRE: سیستم را ۳ بار پشت‌سرهم هنگام بوت قطع کنید (روشن کن → قطع برق)، یا از منوی بوت (F11 / Esc / F12) یا فلش نصب ویندوز → Repair your computer استفاده کنید.
  2. باز کردن Command Prompt: از مسیر Troubleshoot → Advanced options → Command Prompt.
  3. پیدا کردن حرف فلش: حرف‌ها با حالت عادی فرق دارند! با dir c: و dir d: و dir e: فلش را پیدا کنید.
  4. اجرا: مثلاً e:\DriveHelper.bat — برنامه خودش می‌فهمد در Recovery است و منوی نجات را نشان می‌دهد.
  5. ترتیب پیشنهادی: اول گزینه‌ی ۱ (لیست درایوها) ← بعد ۲ (نجات فایل‌ها) ← بعد ۵ (تعمیر بوت) ← بعد ۳ (chkdsk) ← بعد ۴ (SFC آفلاین).

When Windows will not boot

Inside Windows Recovery (WinRE) the program automatically switches to Recovery Mode and only uses tools that actually exist there.

Important WinRE usually has no internet: WiFi almost never works, wired sometimes via wpeutil InitializeNetwork. Online repairs are therefore intentionally excluded from this mode.
  1. Enter WinRE: cut power 3 times in a row during boot, or use the boot menu (F11 / Esc / F12), or a Windows install USB → Repair your computer.
  2. Open Command Prompt: via Troubleshoot → Advanced options → Command Prompt.
  3. Find your USB letter: letters differ from normal Windows! Try dir c:, dir d:, dir e:.
  4. Run: e.g. e:\DriveHelper.bat — it detects Recovery automatically and shows the rescue menu.
  5. Recommended order: 1 (list drives) → 2 (rescue files) → 5 (boot repair) → 3 (chkdsk) → 4 (offline SFC).

راهنمای استفاده

  1. دانلود: فایل DriveHelper.bat را از دکمه‌ی بالا دریافت و روی فلش USB بریزید (یا با گزینه‌ی ۷ روی هاردهای خودتان کپی کنید).
  2. اجرا: روی سیستم هدف دابل‌کلیک کنید. اگر ابزاری دسترسی ادمین بخواهد، خودش پنجره‌ی UAC باز می‌کند.
  3. پیدا کردن کار: اول لیست درایوها بالای منو را بخوانید (حجم کل / اشغال‌شده / آزاد)، بعد شماره‌ی گزینه را تایپ کنید.
  4. هش را چک کنید: برای اطمینان از سالم بودن فایل، SHA-256 آن را با مقدار پایین صفحه مقایسه کنید.
نکته اولین اجرا پیشنهاد می‌دهد با دسترسی Administrator باز شود تا همه‌ی ابزارها فعال باشند؛ این اختیاری است.

How to use

  1. Download: get DriveHelper.bat with the button above and put it on a USB stick (or use option 7 to copy it onto your own drives).
  2. Run: double-click on the target PC. If a tool needs admin rights, the program relaunches itself via UAC.
  3. Pick a job: read the drive list at the top of the menu (total / used / free), then type an option number.
  4. Verify: compare the file's SHA-256 with the value at the bottom of this page.
Tip on first run it offers to relaunch as Administrator so every tool is available — this is optional.

سؤالات متداول

آنتی‌ویروس رویش هشدار می‌دهد — چرا؟
ترکیب «اسکریپت + اجرای ادمین + کارهای سیستمی مثل SFC و بوت» الگوی آشنایی برای آنتی‌ویروس‌هاست (هیوریستیک). فایل متن‌باز است و می‌توانید سورسش را خط‌به‌خط بخوانید؛ روی سیستم خودتان استثناش کنید.
روی چه ویندوزی کار می‌کند؟
Windows 8.1 / 10 / 11 هر دو معماری ۳۲ و ۶۴ بیتی. حالت نجات در WinRE این نسخه‌ها هم کار می‌کند.
فلش Rescue بوت نمی‌شود؟
۱) ترتیب بوت را از BIOS عوض کنید (F12/Esc/F9). ۲) اگر Secure Boot فعال است، موقتاً خاموشش کنید. ۳) فلش باید FAT32 و حداکثر ۳۲ گیگابایت باشد. ۴) این فلش فقط روی سیستم‌های UEFI (تقریباً همه‌ی سیستم‌های ۲۰۱۳ به بعد) بوت می‌شود.
بکاپ تصویری کامل (گزینه ۹-۳) جواب نمی‌دهد؟
ابزار wbadmin روی ویندوزهای Home نیست؛ برنامه خودش تشخیص می‌دهد. جایگزین: بکاپ پوشه‌های کاربر (۵-۱) یا زیپ کردن درایو (۳-۳).
چرا FAT32 روی فلش بزرگ‌تر از ۳۲ گیگ خطا می‌دهد؟
محدودیت خودِ ویندوز است، نه برنامه. برای فلش‌های بزرگ‌تر exFAT یا NTFS انتخاب کنید.
امنیت رمز وای‌فای‌ها چی؟
گزینه‌ی «نمایش رمز» فقط پروفایل‌های همون سیستم کاربر را می‌خواند — هیچ داده‌ای از سیستم دیگری جمع نمی‌شود. فایل‌های خروجی رمز را به‌صورت خام دارند؛ بعد از استفاده پاکشان کنید.

FAQ

My antivirus flags it — why?
"script + admin relaunch + system-level repairs like SFC/boot" matches heuristic patterns. The file is open source — read every line yourself, then allow it on your own machine.
Which Windows versions are supported?
Windows 8.1 / 10 / 11, both 32- and 64-bit. Recovery Mode works in those versions' WinRE too.
The rescue USB will not boot?
1) Change boot order in BIOS (F12/Esc/F9). 2) Temporarily disable Secure Boot. 3) The stick must be FAT32, max 32 GB. 4) It boots on UEFI systems only (virtually all PCs since 2013).
Full image backup does not work?
wbadmin is missing on Windows Home editions; the program detects this itself. Alternatives: user folder backup (5-1) or zipping the drive (3-3).
Why does FAT32 fail on drives over 32 GB?
That is a Windows limitation, not the tool's. Pick exFAT or NTFS for larger drives.
What about WiFi password security?
The "show passwords" option only reads profiles of the local machine — nothing is collected from anyone else's system. Export files contain plaintext passwords; delete them after use.
